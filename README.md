# BlackAsta-Farming-Bot
Bot de Python para automatizar BlackAsta. Requiere ordenador (WhatsApp Web o app de escritorio), Python 3 y PyAutoGUI. Instala con pip install pyautogui. Abre WhatsApp, entra al chat, abre CMD en la carpeta del bot y ejecuta python bot.py para iniciarlo. EL CREADOR NO SE HACE RESPONSABLE DEL USO INDEBIDO DEL BOT.
